# MCP Toolkit для 1С

Внешняя обработка `MCP Toolkit` — MCP-сервер (Model Context Protocol) для «1С:Предприятие 8.3».
Работает внутри клиентского сеанса 1С: поднимает встроенный HTTP-сервер и предоставляет
AI-агенту инструменты для работы с базой: запросы, выполнение кода, метаданные, журнал
регистрации, права, ссылки, скриншоты.

- `serverInfo`: `1C MCP Toolkit (Native)` **1.0.0**
- Протокол MCP: **2024-11-05** (Streamable HTTP + SSE)
- Порт по умолчанию: **6003**
- Тип: внешняя обработка (`.epf`), исходники — XML-выгрузка формата 8.3.27

## Быстрый старт

Одна команда поднимает сеанс 1С вместе с MCP-сервером:

```powershell
& "C:\Program Files\1cv8\8.3.27.2214\bin\1cv8.exe" ENTERPRISE `
  /S"localhost/base" /N"<пользователь>" /P"<пароль>" `
  /Execute "C:\path\to\MCP_Toolkit.epf" `
  /C "startup;mode=embedded;port=6003"
```

Проверка: `python scripts/check-mcp.py` — печатает `serverInfo`, протокол и список инструментов.

Подробности: параметры `startup;`, проверка, подключение в OpenCode и частые ошибки —
в [docs/START.md](docs/START.md).

## Возможности

| Инструмент | Назначение |
|---|---|
| `execute_query` | Выполнить запрос на языке 1С (лимиты, пагинация, схема результата) |
| `execute_code` | Выполнить фрагмент кода 1С в сеансе |
| `get_metadata` | Метаданные конфигурации: объекты, реквизиты, табличные части, движения |
| `get_event_log` | Журнал регистрации за период с фильтрами |
| `get_object_by_link` | Получить объект по ссылке |
| `get_link_of_object` | Получить ссылку/навигационную ссылку объекта |
| `find_references_to_object` | Найти ссылки на объект в данных и метаданных |
| `get_access_rights` | Права доступа: роли, эффективные права, RLS |
| `get_bsl_syntax_help` | Справка по синтаксису BSL |
| `get_screenshot` | Скриншот окна 1С (с подсветкой областей) |
| `restart_1c_session` | Перезапустить сеанс 1С (сохранение параметров) |
| `close_1c_session` | Закрыть сеанс 1С |
| `submit_for_deanonymization` | Отправить значения на деанонимизацию |

Дополнительно поддерживается REST-доступ: `POST /api/<имя_инструмента>`.

## Требования

- «1С:Предприятие» 8.3 (проверено на 8.3.27.2214/2342), тонкий или толстый клиент;
- база, в которой разрешён запуск внешних обработок и использование встроенного HTTP-сервера;
- для сборки/разбора `.epf` — установленная платформа и база с конфигурацией (см. ниже).

## Запуск

```bat
"C:\Program Files\1cv8\8.3.27.2214\bin\1cv8.exe" ENTERPRISE ^
  /S"<сервер>/<база>" /N"<пользователь>" /P"<пароль>" ^
  /Execute "<путь>\MCP_Toolkit.epf" ^
  /C "startup;mode=embedded;port=6003" ^
  /DisableStartupDialogs
```

Параметры `/C`:

| Параметр | Значения | Смысл |
|---|---|---|
| `startup` | — | Включить сервер при старте (без него форма открывается обычным окном) |
| `mode` | `embedded` \| `proxy` | Встроенный HTTP-сервер или подключение к внешнему MCP-прокси |
| `url` | URL | Адрес внешнего прокси (для `mode=proxy`) |
| `port` | 1…65535 | Порт встроенного сервера (по умолчанию 6003) |
| `channel` | строка | Канал/метка подключения |
| `auth` | `windows` \| `password` | Режим аутентификации прокси |
| `pwd` | строка | Пароль для `auth=password` |

Служебные режимы `autostart;<timestamp>;<params.json>` и `coldstart;<timestamp>;<params.json>`
используются внутренне инструментами `restart_1c_session` / `close_1c_session` для перезапуска
сеанса и вручную не задаются.

Пример:

```bat
1cv8.exe ENTERPRISE /S"localhost/task" /N"Пользователь" /P"***" ^
  /Execute "E:\tools\MCP_Toolkit.epf" /C "startup;port=6003" /DisableStartupDialogs
```

## Сборка и разбор

Команды используют навыки `cc-1c-skills` (`epf-build`, `epf-dump`). Сборка выполняется
через Конфигуратор, поэтому база должна быть свободна (Конфигуратор закрыт), а путь к
платформе и базе — соответствовать вашему окружению.

```powershell
# XML-исходники → EPF
powershell -NoProfile -File ".opencode\skills\epf-build\scripts\epf-build.ps1" `
  -V8Path "C:\Program Files\1cv8\8.3.27.2214\bin" `
  -InfoBaseServer "KOMPUTER" -InfoBaseRef "<база>" -UserName "<пользователь>" `
  -SourceFile "E:\project\mcp_1c_tools\src\MCPToolkit.xml" `
  -OutputFile "E:\project\mcp_1c_tools\MCP_Toolkit.epf"

# EPF → XML-исходники
powershell -NoProfile -File ".opencode\skills\epf-dump\scripts\epf-dump.ps1" `
  -V8Path "C:\Program Files\1cv8\8.3.27.2214\bin" `
  -InfoBaseServer "KOMPUTER" -InfoBaseRef "<база>" -UserName "<пользователь>" `
  -InputFile "E:\project\mcp_1c_tools\MCP_Toolkit.epf" `
  -OutputDir "E:\project\mcp_1c_tools\src"
```

Проверка результата без UI: `ВнешниеОбработки.Создать(<epf>)` → сервер слушает порт →
`/health` возвращает `healthy`.

## Грабли

- **Сеанс 1С как дочерний процесс агента.** Если запустить `1cv8.exe` из shell-инструмента,
  клиент завершается вместе с командой и MCP-сервер не удержится. Запускайте отдельно:
  вручную, из Планировщика задач или через `start ""`.
- **Лицензии.** Запуск MCP-сеанса с `/UseHwLicenses+` может вытеснить программную лицензию
  и уронить параллельно работающий Конфигуратор.
- **Блокировка базы.** `epf-build`/`epf-dump` падают, если база открыта Конфигуратором.
- **Опасные операции разрешены.** Подтверждение записи/удаления отключено намеренно:
  инструменты могут менять данные. Используйте на тестовых и демонстрационных базах.

# Быстрый старт: сеанс 1С с MCP Toolkit

Как поднять встроенный MCP-сервер обработки и подключиться к нему.

## 1. Что нужно

| Компонент | Требование |
|---|---|
| Платформа | «1С:Предприятие 8.3» (тонкий клиент), например `8.3.27.2214` |
| Обработка | `MCP_Toolkit.epf` из этого репозитория (собирается из `src/`) |
| База | любая: файловая (`/F`) или серверная (`/S`) |
| Порт | свободный, по умолчанию `6003` |

## 2. Запуск

```powershell
& "C:\Program Files\1cv8\8.3.27.2214\bin\1cv8.exe" ENTERPRISE `
  /S"localhost/task" /N"<пользователь>" /P"<пароль>" `
  /Execute "C:\path\to\MCP_Toolkit.epf" `
  /C "startup;mode=embedded;port=6003"
```

Ключевой элемент — `/C "startup;..."`: обработка разбирает его в `ПриОткрытии` и сама
поднимает HTTP-сервер. Без него форма откроется, но порт слушать не будет.

Файловая база: `/F"C:\base"` вместо `/S`. Серверная может быть записана как
`/Sserver/base` или `/IBConnectionString "Srvr=""server"";Ref=""base"""`.

### Параметры startup

| Ключ | Значения | Назначение |
|---|---|---|
| `mode` | `embedded` / `proxy` | встроенный сервер в сеансе или прокси к внешнему |
| `port` | 1–65535 | порт встроенного сервера (по умолчанию 6003) |
| `url` | адрес | адрес сервера для режима `proxy` |
| `auth` | `windows` / `password` | режим аутентификации перезапуска |
| `pwd` | строка | пароль для `auth=password` |
| `channel` | строка | идентификатор канала |

## 3. Проверка

```bash
python scripts/check-mcp.py http://127.0.0.1:6003/mcp
```

Ожидается `1C MCP Toolkit (Native) 1.0.0`, протокол `2024-11-05`, 13 инструментов.

Ручная проверка (любой MCP-клиент): `initialize` → `tools/list` → `tools/call`.
Транспорт — Streamable HTTP: POST на `/mcp`, заголовок `mcp-session-id` из ответа,
Accept `application/json, text/event-stream`.

## 4. Подключение в OpenCode

```jsonc
"1c": { "type": "remote", "url": "http://127.0.0.1:6003/mcp", "enabled": true }
```

Если сервер поднят уже после запуска OpenCode, namespace появляется после
перечитывания конфигурации (`/reload`).

## 5. Частые проблемы

| Симптом | Причина | Решение |
|---|---|---|
| Окно входа, порт не открывается | не переданы `/N` и `/P` | передать учётные данные |
| Клиент сразу закрылся | неверная база или пароль | проверить строку подключения |
| Порт занят | другой сеанс 1С на этом порту | закрыть его или выбрать другой `port` |
| Инструменты не отвечают | сеанс закрыт | окно 1С должно оставаться открытым |
| Ошибка версии платформы | у базы свой `DefaultVersion` | запускать платформой из «Сервис → Параметры» базы |

## 6. Безопасность

- Пароль не хранится в репозитории: используйте переменную окружения, диспетчер
  секретов или локальный файл вне git (`secrets/`, `.1c/` — в `.gitignore`).
- Сеанс 1С работает с полными правами пользователя. Для экспериментов с данными
  используйте копию базы.
- Инструменты `execute_code` и `execute_query` не ограничены чтением — это надо
  учитывать при выдаче доступа агенту.
